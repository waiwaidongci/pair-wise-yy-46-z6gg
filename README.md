# 商业财产保险理赔查勘与定损审核工作台

面向理赔员、专家与主管的商业财产险查勘工作台，覆盖损失科目、修复报价、残值、责任比例、准备金会签、争议项、附件版本和审计时间线。

## 技术栈

Angular + Angular Material + NgRx + Angular Router + HttpClient + RxJS + Angular CLI + TypeScript

## 本地运行

```bash
npm install
npm run start
```

访问 `http://localhost:62046`。

## 核心工作流

- 按案件和损失科目录入查勘事实、照片、报告与保单摘录。
- 调整修复报价时强制填写理由，并保留前后差异。
- 准备金按金额与风险阈值触发多级会签，可退回补件。
- 对比赔付方案、定位争议项、上传附件版本并导出完整审计记录。

## 离线同步与冲突合并

- 查勘保存不再整案覆盖：科目改动与附件版本改动分别打包成带操作号（OP-0001…）的待同步项进入队列，草稿每次提交也生成独立操作号，多人草稿不再互相覆盖。
- 同步按操作号顺序提交；服务端按操作号幂等记账，已生效的写入重复提交不会重复入账。
- 合并按科目和附件分别进行：同一字段两边都改过时保留本地版本，并在同步队列与审计页列出冲突（本地值 / 对方值）。
- 同步失败后操作保留在队列中并记录尝试次数，审计时间线追加「同步失败 / 同步重试」记录，可单项或全部重试；刷新页面后进度不丢。
- 旧版本地数据兼容：纯文本草稿在首次启动时按当前案件补成初始待同步项。
- 同步面板提供「模拟离线」「模拟他人保存」用于演示失败重试与冲突合并。
